# 기술 부채 장부 (Tech Debt Ledger)

> 2026-08-25 시작. **본배치 전 범위 동결** 기간에 "알면서 미룬 것"을 기록한다.
> 규칙: 배치 전에는 QA에서 참가자가 실제로 부딪힌 결함만 고친다. "하는 김에" 개선은
> 여기 적고 미룬다. 본배치 종료 후 이 장부 순서로 정리 패스를 돈다.
> 항목 형식: 현재 패치(어디에 뭘 덧댔나) / 진짜 원인 / 제대로 된 수정 / 상환 시점.

## D1. 기준 이중 통로 — 같은 요구가 판정행렬에 두 칸으로 들어감

- **현재 패치**: 카드 표시 직전 hardUnk 라벨 dedup(정규화 일치) + 카운트 라벨 단위 집계
  (`response_generator.py` 행렬 후처리, 2026-08-25). `'lightweight, lightweight'` 증상만 제거.
- **진짜 원인**: 사용자 모델 칩과 recommendation_spec의 hardConstraints가 **각각 별도 cid**로
  리랭크 criteria에 들어간다. 같은 요구를 두 번 판정하고, 행렬이 불필요하게 커진다.
- **제대로 된 수정**: criteria 조립 시점에 정규화 일치 라벨을 한 cid로 병합 (집행 의미
  enforcement가 다르면 강한 쪽 우선). 리랭크 계약·mock·테스트 동반 수정 필요.
- **상환**: 본배치 후.

## D2. 응답 프롬프트 룰 누적 — 18개, 전부 사고 후 추가분

- **현재 패치**: AGENT_REPLY_SYSTEM 룰 15~18 등 사고당 룰/예시 1개씩 추가하는 러닝머신.
- **진짜 원인**: LLM 자유 텍스트의 사실성은 프롬프트 규칙으로 보장 불가 — 규칙은 확률만 옮긴다.
- **제대로 된 수정**: (a) 룰 통합 재작성 — 원칙 몇 개 + 예시 은행으로 재편, 전 행동 재검증 필요.
  (b) 사실 문장의 결정론화 — 가격·충족/미확인 목록 등 사실 파트는 코드가 조립하고 LLM은 윤문만.
- **상환**: 본배치 후. (b)가 우선 검토 대상.

## D3. 종료 흐름 재개 분기 — 로드 시 케이스 3개로 산개

- **현재 패치**: VariantSession 로드 시 `finalChoice/postSurvey/criterionAudit` 존재 여부로
  분기 3개 (CC 재개 / 감사 재개 / 완료 화면). 2026-08-25까지 사고당 하나씩 추가됨.
- **진짜 원인**: 종료 절차(최종 선택→CC→감사→다음 과제/최종 설문)가 암묵 상태 기계인데
  상태가 meta 필드 조합으로 흩어져 있고 정식 전이 정의가 없다.
- **제대로 된 수정**: 종료 단계를 명시적 상태 필드(예: `meta.finishStage`)로 저장하고,
  로드 시 그 상태에서 재개하는 단일 함수로 통합.
- **상환**: 본배치 후. **⚠ 이번 물결 잠김** — b1 배치(8/26)가 현 절차로 돌았으므로
  종료 절차 변경은 조건 간 절차 불일치를 만든다. 전 조건 배치 종료 전 변경 금지.

## D4. LLM 사실 주장의 구조적 검증 부재 (카드 ✓·본문 서술)

- **현재 패치**: unk 명시 강제, 카테고리 통념 추측 금지, "모두 충족" 금지, 미확인 속성
  컨텍스트 필드 등 프롬프트·데이터 개입 (2026-08-24~25). 확률 감소이지 보장 아님.
- **진짜 원인**: 스트라이프 셔츠에 "✓White color"가 찍혀도 코드가 걸러낼 방법이 없다 —
  셀은 주장일 뿐 근거를 요구받지 않는다.
- **제대로 된 수정**: 카드 matched 항목에 상품 텍스트 원문 인용을 요구하고 코드가 문자열
  대조로 검증, 불일치 ✓ 폐기 (= ④). 지연 +1~2초, 계약 변경.
- **상환 진행 (2026-08-26)**: 카드 matched 인용 검증을 fix/revision-v2 브랜치에 구현·검증

  자유 문장은 여전히 미검증 (D2의 결정론화와 함께 본배치 후).

## D6. 과제 상황문 CRS 주입 — 설계 합의, 구현 보류

- **현재 상태**: 과제 상황("왕복 2시간 통근")이 프론트에만 있고 CRS는 카테고리명만 안다.
  참가자가 발화로 옮기지 않으면 1턴이 상황 무관 추천이 된다.
- **합의된 설계**: 공유 과제 맥락(세 조건 공통 주입: planner/rerank/renderer) / 개인 증거

- **상환**: **⚠ 이번 물결 잠김 (2026-08-26)** — b1 배치가 상황문 미주입으로 돌았다.
