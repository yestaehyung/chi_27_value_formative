## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Study language

The participant study UI is Korean by default. To run a separate English
frontend deployment while sharing the same pages and interaction logic:

```bash
NEXT_PUBLIC_STUDY_LOCALE=en npm run dev
```

English survey copy lives in `lib/mainSurvey.en.ts`; shared study interface
copy and category labels live in `lib/studyI18n.ts`. Single-choice responses
are converted back to the existing canonical values before API submission so
Korean and English exports remain comparable.

This switch covers participant-facing frontend copy. Agent-generated messages,
inferred criteria, evidence text, and product fields use the language returned
by the backend and catalog, so a fully English study also requires an English
backend prompt/content configuration.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
